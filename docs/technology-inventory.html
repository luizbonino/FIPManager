Data storage

SQLite in WAL mode, as a single file on a mounted volume. There is no database server to provision, patch or back up separately — the backup unit is that one file.

Personal data held: account email addresses and Argon2 password hashes, server-side session records, and any free text participants type into their profiles. Retention for profiles created without an account is 12 months, enforced by an operator-run command rather than a scheduler.

No third-party content at runtime

The browser application loads no scripts, fonts, stylesheets or images from any external host. Everything it needs is served from the application's own origin, so it works fully on an isolated network or a laptop hotspot.

What the deployment needs from you

  • SetFIPM_SECRET_KEY to a generated secret. The default is a known development value.
  • SetFIPM_ENV=production so the guard above is active.
  • SetFIPM_BASE_URL to the real public URL — profile identifiers and QR join links are built from it.
  • ProvideTLS. The application speaks plain HTTP and expects to sit behind a reverse proxy that terminates HTTPS.
  • SetFIPM_CONTACT_EMAIL and FIPM_HOSTING_ORG. They appear in the privacy notice.
