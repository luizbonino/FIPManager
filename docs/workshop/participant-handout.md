# Your FIP — One-Page Guide

**What is a FIP?** A FAIR Implementation Profile (FIP) is a short, structured declaration of which concrete technologies a community uses to make its data and metadata Findable, Accessible, Interoperable and Reusable. It answers 21 questions grouped by the four FAIR letters, one technology choice per question. Unlike a policy statement, a FIP is precise and comparable: it names actual identifier schemes, protocols, vocabularies and licences, not general intentions.

**What is a FER?** A FAIR Enabling Resource (FER) is the specific technology, service or standard you name as your answer — the thing that does the FAIR-enabling work. Examples: **DOI** (a persistent identifier service — "which identifiers for your data?") and **Dublin Core** (a metadata schema — "which schema for findability?"). Not in the list? Type it as free text — expected and just as valid.

**The five statuses, one line each:**

- **Currently used** — your community does this today.
- **Planned** — you intend to start using it.
- **To be developed** — the resource doesn't exist yet; someone needs to build it.
- **To be replaced** — used today, but you plan to move away (add a second answer for its replacement).
- **No choice yet** — an honest "we haven't decided," not a skip; it still counts as answered.

**How to join and save:** scan the QR code or type the join code from the projector into your phone's browser. Pick a name for your community and start answering — saving is automatic, a couple of seconds after you stop typing (watch the "Saved" indicator). Only the device that started the FIP can edit it; any other device gets a read-only view.

**Where is your FIP's URL?** Open the "Share" panel in your editor — it shows your FIP's permanent URL and a QR code to scan or send to teammates. Keep that link; it still works after today, and you can create a free account any time to claim the FIP into your own workspace.

# O Seu FIP — Guia de Uma Página (pt-PT)

**O que é um FIP?** Um FAIR Implementation Profile (FIP) é uma declaração curta e estruturada de que tecnologias concretas uma comunidade utiliza para tornar os seus dados e metadados Localizáveis, Acessíveis, Interoperáveis e Reutilizáveis. Responde a 21 perguntas agrupadas pelas quatro letras de FAIR, uma escolha tecnológica por pergunta. Ao contrário de uma declaração de política, um FIP é preciso e comparável: nomeia esquemas de identificadores, protocolos, vocabulários e licenças reais, não intenções gerais.

**O que é um FER?** Um FAIR Enabling Resource (FER) é a tecnologia, serviço ou norma específica que indica como resposta — aquilo que realiza o trabalho de tornar FAIR. Exemplos: **DOI** (serviço de identificadores persistentes — "que identificadores para os seus dados?") e **Dublin Core** (esquema de metadados — "que esquema para a localizabilidade?"). Não está na lista? Escreva-o em texto livre — é esperado e igualmente válido.

**Os cinco estados, numa linha cada:**

- **Atualmente utilizado** — a vossa comunidade faz isto hoje.
- **Planeado** — pretendem começar a usar.
- **A desenvolver** — o recurso ainda não existe; alguém tem de o construir.
- **A substituir** — usado hoje, mas planeiam abandoná-lo (acrescentem uma segunda resposta para o substituto).
- **Sem escolha ainda** — um "ainda não decidimos" honesto, não uma pergunta saltada; conta como respondida.

**Como aderir e guardar:** digitalizem o código QR ou introduzam o código de acesso do projetor no navegador do telemóvel. Escolham um nome para a vossa comunidade e comecem a responder — a gravação é automática, poucos segundos depois de pararem de escrever (indicador "Guardado"). Só o dispositivo que iniciou o FIP o pode editar; qualquer outro dispositivo vê uma versão apenas de leitura.

**Onde está o URL do vosso FIP?** Abram o painel "Partilhar" no editor — mostra o URL permanente do FIP e um código QR para digitalizar ou enviar à equipa. Guardem esse link; continua a funcionar depois de hoje, e podem criar uma conta gratuita a qualquer momento para reivindicar o FIP para o vosso espaço.
